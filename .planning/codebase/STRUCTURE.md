# Codebase Structure

**Analysis Date:** 2026-09-16

## Directory Layout

```text
[project-root]/
├── .planning/          # GSD planning and codebase mapping docs
├── api/                # Vercel Serverless functions (Backend)
├── android/            # Capacitor Android native project
├── docs/               # Architecture Decision Records (ADR) and manuals
├── public/             # Static assets (images, icons, fonts)
├── src/                # Main source code
│   ├── api/            # Client-side API definitions / shims
│   ├── components/     # Reusable UI components
│   │   ├── shared/     # Domain-agnostic helpers (ErrorBoundary, etc.)
│   │   └── ui/         # Base Radix-based primitives (Button, Input)
│   ├── features/       # Feature-based UI modules (Encapsulated)
│   │   ├── dashboard/  # Main overview and stats
│   │   ├── interview/  # Mock interview sessions and feedback
│   │   ├── resume-*/   # Resume analysis and builder features
│   │   └── history/    # Past session logs
│   ├── hooks/          # Global React hooks
│   ├── lib/            # Infrastructure (DB, Logger, Utils)
│   ├── services/       # Business logic and domain services
│   │   ├── ai/         # Core AI SDK integration and fallback
│   │   ├── interview/  # Interview logic and streaming
│   │   ├── prompts/    # Domain-split AI prompt templates
│   │   └── resume/     # Parsing and CV chat logic
│   └── types/          # TypeScript domain definitions
└── tailwind.config.ts  # Styling configuration
```

## Directory Purposes

**`src/features/`:**
- Purpose: Contains independent modules representing application capabilities.
- Contains: `components/`, `hooks/`, `stores/`, and `pages/` for each domain.
- Key files: `InterviewSession.tsx`, `useInterviewStore.ts`.

**`src/services/`:**
- Purpose: Pure logic layer for AI, data processing, and external integrations.
- Contains: Classes and functions that are UI-agnostic.
- Key files: `src/services/ai/ai.service.ts`, `src/services/prompts/promptSystem.ts`.

**`src/lib/`:**
- Purpose: Shared utilities and database wrappers.
- Contains: Low-level implementation details.
- Key files: `db.ts` (Dexie), `logger.ts`, `resumeCompression.ts`.

**`src/components/ui/`:**
- Purpose: Reusable atomic UI elements.
- Contains: Styled primitives using Tailwind CSS v4.
- Key files: `button.tsx`, `card.tsx`, `dialog.tsx`.

## Key File Locations

**Entry Points:**
- `src/index.tsx`: Application bootstrap.
- `src/App.tsx`: Main router and provider configuration.

**Configuration:**
- `package.json`: Dependencies and script definitions.
- `capacitor.config.ts`: Mobile build and bridge configuration.
- `.env.example`: Environment variable templates.

**Core Logic:**
- `src/services/ai/ai.service.ts`: Central AI communication engine.
- `src/lib/db.ts`: IndexedDB database schema and migrations.

**Testing:**
- `src/setupTests.ts`: Vitest global setup.
- `src/**/*.test.ts(x)`: Co-located unit and integration tests.

## Naming Conventions

**Files:**
- Components: `PascalCase.tsx` (e.g., `ChatPanel.tsx`).
- Hooks: `camelCase.ts` starting with `use` (e.g., `useAuth.ts`).
- Services/Utils: `camelCase.ts` (e.g., `dateUtils.ts`).

**Directories:**
- Feature folders: `kebab-case` (e.g., `resume-analysis`).
- Internal module folders: `camelCase` (e.g., `hooks`, `stores`).

## Where to Add New Code

**New Feature (e.g., "Company Research"):**
- Primary code: `src/features/company-research/`
- UI: `src/features/company-research/components/`
- State: `src/features/company-research/stores/researchStore.ts`
- Tests: `src/features/company-research/**/*.test.ts`

**New AI Provider (e.g., "DeepSeek"):**
- Implementation: `src/services/ai/strategies/deepseekStrategy.ts`
- Registration: Add to `src/services/ai/aiCandidateResolver.ts`.

**Shared Utility:**
- Implementation: `src/lib/` or `src/hooks/` if React-dependent.

## Special Directories

**`api/` (Root):**
- Purpose: Vercel serverless functions for secure operations (Sync, Auth).
- Generated: No.
- Committed: Yes.

**`android/`:**
- Purpose: Native Android project generated by Capacitor.
- Generated: Partially (managed via `npm run android`).
- Committed: Yes.

**`src/services/prompts/`:**
- Purpose: Repository for all system and user prompt templates to prevent prompt-injection or sprawl.
- Generated: No.
- Committed: Yes.
